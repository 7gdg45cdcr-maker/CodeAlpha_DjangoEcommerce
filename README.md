# Django E-Commerce Store

A full-stack e-commerce web application developed as part of the CodeAlpha Full Stack Development Internship.

## Features

- User registration and authentication
- Product listing
- Product details
- Shopping cart
- Add/remove/update cart items
- Checkout
- Order processing
- Order history
- Django Admin
- SQLite database
- Responsive user interface

## Technology Stack

Frontend:
HTML5, CSS3, JavaScript

Backend:
Python, Django

Database:
SQLite

Tools:
VS Code, Git, GitHub

## Application Workflow

Register → Login → Browse Products → Product Details → Add to Cart → Checkout → Place Order → My Orders
